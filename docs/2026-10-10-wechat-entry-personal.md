# PaperFlow 微信入口落地指南 · 个人主体版

日期：2026-10-10。目标：让"手机微信发链接/DOI → 电脑自动整理进 Zotero → 结果回微信"在**个人主体、无自有服务号**的前提下落地。

## 一、结论先行

**"正式服务号"在个人主体下无法申请**——服务号仅限企业/组织主体，个人只能申请订阅号（订阅号没有消息回调权限）。这是微信公众平台的硬性规则。

但你的目标**不需要自有服务号也能实现**，用 **WorkBuddy 微信助理**（官方内置的"微信客服号/微信助理"集成）：

- 个人可用，**无需申请服务号、无需 AppID/AppSecret、无需域名、无需服务器**
- 微信扫码绑定即可
- 手机微信发指令 → 电脑上的 WorkBuddy 本地执行 → 结果回传微信

这条路和你最初"统一入口、微信接收文献"的目标一致，只是入口从"自有服务号"换成"WorkBuddy 微信助理"。

## 二、三种微信入口对比

| 入口 | 主体要求 | 消息回调 | 能落地吗 | 适用 |
| --- | --- | --- | --- | --- |
| 测试号 | 个人可申请 | ✅ | ✅（已验证） | 开发调试 |
| **WorkBuddy 微信助理** | 个人可用 | ✅（WorkBuddy 转发） | ✅ **推荐** | 个人日常使用 |
| 自有服务号 | 仅企业/组织 | ✅ | ❌ 个人不可 | 未来正式分享 |

## 三、WorkBuddy 微信助理接入步骤

前置条件：WorkBuddy ≥ 4.6.4、手机微信 ≥ 8.0.70、电脑和手机能上网、**电脑保持开机且 WorkBuddy 运行**。

1. 打开 WorkBuddy 电脑端 → 头像 → **助理设置**（或"设置 → 助理设置"）。
2. 集成列表中找到 **"微信助理" / "微信客服号"** → 点右侧 **"配置"**。
3. 出现二维码后，用手机微信**扫码绑定**（二维码有时效，过期重新点"配置"）。
4. 状态变为 **"已绑定"** 并显示微信头像/昵称即成功。
5. 发一条测试消息验证：如"帮我查看 PaperFlow 队列"。

关键机制：手机微信只发指令和批准操作；**所有执行都在你的电脑本地**（项目文件、Shell、凭证、插件、工具），执行结果同步回微信。电脑休眠/断网/关 WorkBuddy 时远程访问会中断。

## 四、绑定后的完整工作流

```
手机微信发：DOI 或 公众号文章链接
        ↓
WorkBuddy 微信助理（转发指令到你的电脑）
        ↓
电脑 WorkBuddy 调用 paperflow-workbuddy 技能
        ↓
batch/orchestrate.py：领取 → 解析 → scansci-pdf 下载 → Zotero 入库 → 观察
        ↓
结果（已下载/未下载清单/阻塞项）回传微信
```

已就绪的组件：
- **编排器** `batch/orchestrate.py`：端到端流水线（单实例锁、有界、幂等、下载走 scansci 套件）。
- **技能** `paperflow-workbuddy`：操作顺序与安全边界（需在 WorkBuddy 导入启用）。
- **定时自动化**：每天 14:00 运行一次编排器处理队列（WorkBuddy automation，id df05bc30）。

## 五、需要你手动完成的两件事

1. **绑定微信助理**：按第三节扫码绑定（这是你自己在 WorkBuddy 界面的操作，我无法代做）。
2. **导入并启用 paperflow-workbuddy 技能**：技能 → 添加技能 → 上传 `paperflow-workbuddy-0.2.0-local-client.zip`。

绑定后，你在微信里发 DOI/链接，就能触发电脑上的整理流程。

## 六、诚实边界（当前仍受限）

- **不是"自有统一服务号"**：依赖 WorkBuddy 微信助理，且消息到达会切换 WorkBuddy 内部助理页面，不能承诺完全不打扰。
- **电脑必须开机 + WorkBuddy 运行**：不是独立服务器，电脑关了就不接收。
- **scansci 来源策略仅 Nature 验证过**：其他出版社尚未核验，遇到会标 needs_configuration。
- **Zotero 需运行**：入库需要插件 0.7.0 接口（127.0.0.1:23119）在线。
