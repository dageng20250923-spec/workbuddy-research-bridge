# PaperFlow 用户手册 · 安装与使用

版本：0.2.0-local（本地验证版）

本文面向**想要在自己的电脑上自行安装运行 PaperFlow 的用户**。PaperFlow 是一套「微信 PDF → Zotero 自动分类 → Obsidian 文献笔记」的个人文献整理工作流，包含：微信回调接收器、目录扫描分流器、端到端下载入库编排器、以及一个 WorkBuddy 技能。

> 重要：本项目是**本地单机工具**，不是开箱即用的公共 SaaS 服务。安装后需要你在自己电脑上配置 Zotero、Obsidian、微信文件目录等本机路径，才能运行。请完整阅读本手册后再动手。

## 1. 项目能做什么

PaperFlow 把「从微信收到 PDF 到在 Obsidian 里读文献」这条链路自动化，分四段：

| 环节 | 负责模块 | 是否自动 |
|---|---|---|
| ① 扫描微信文件目录、分流论文/个人资料 | `batch/scan_pdf_dir.py` | 自动 |
| ② 论文下载（按 DOI/链接，走 scansci 套件） | `batch/orchestrate.py` + `scansci_adapter.py` | 自动 |
| ③ 导入 Zotero 并按成像方法分类 | 插件 `/wechat-zotero/import` + 分类器 | 自动 |
| ④ 同步 Obsidian + AI 文献阅读 | Obsidian「Research Bridge」插件 | 半自动（见 §4.4） |

**关于「自动 AI 文献阅读」**：步骤 ④ 依赖第三方 Obsidian 插件 Research Bridge。PaperFlow 只负责把条目送进 Zotero，并**只读观察** Research Bridge 是否已生成笔记与 AI 任务；AI 阅读本身由 Research Bridge 在 Obsidian 里触发，需要你在 Obsidian 内配置 AI 提供商（API Key）后才会自动执行。若未配置，则只有「导入 + 文献卡片」，没有 AI 阅读。

## 2. 前置依赖清单

以下软件**无法通过本项目的安装脚本自动安装**，需要你自行准备：

| 依赖 | 用途 | 最低版本 |
|---|---|---|
| Python | 运行脚本 | 3.10+（推荐 3.11） |
| Zotero | 文献库 | 7.x / 9.x |
| 「微信 PDF 自动整理」Zotero 插件 | 提供 `/wechat-zotero/import` 导入接口 | 0.7.0（XPI 见 §8） |
| Obsidian | 笔记库 | 任意 |
| Obsidian「Research Bridge」插件 | 文献卡片 + AI 阅读 | 任意 |
| scansci-pdf 套件 + 独立 venv | 论文下载 | 需含 certifi |
| 微信（PC 版） | 接收 PDF 的来源 | 任意 |

**Python 环境隔离**：本项目会在自己的目录下创建 `.venv` 虚拟环境，安装脚本**不会**修改系统 Python、不写 PATH、不影响你电脑上其他 Python 环境，两者互不冲突。

## 3. 安装步骤

### 3.1 获取项目代码

将项目目录（含 `batch/`、`receiver/`、`client/`、`docs/`、`workbuddy/`）放到你的数据盘（例如 `D:\PaperFlow\`），目录名建议不含空格。

### 3.2 一键安装 Python 环境（隔离）

在项目根目录打开 PowerShell，运行：

```powershell
powershell -ExecutionPolicy Bypass -File install.ps1
```

或指定自己的 Python 路径：

```powershell
.\install.ps1 -PythonExe "D:\python\python\python.exe"
```

脚本会：
1. 定位 Python 3
2. 创建隔离虚拟环境 `.venv\`
3. 安装 `requirements.txt` 中的依赖（目前仅 `pypdf`）
4. 自检 `pypdf` 可导入

安装成功后会输出项目 Python 路径（`.venv\Scripts\python.exe`），后续所有脚本都用它运行。

### 3.3 手动安装（可选，等价于脚本）

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
```

## 4. 配置说明

### 4.1 安装 Zotero 插件

1. 打开 Zotero → 工具 → 插件 → 右上角齿轮 → 「从文件安装插件…」
2. 选择 `wechat-zotero-importer@example.com.xpi`
3. 安装后**启用**该插件

插件首次启用后会自动生成鉴权 token：`%LOCALAPPDATA%\WeChatZoteroImporter\bridge-token`，脚本通过它调用本地导入接口 `http://127.0.0.1:23119/wechat-zotero/import`。

### 4.2 配置插件设置页

插件启用后，Zotero → 工具 → 插件 → 该插件 → 「选项」，设置：

- **启用后台自动导入**：建议**取消勾选**（让 WorkBuddy 接管扫描，插件只保留导入接口）
- **PDF 来源文件夹**：指向你的微信文件目录（见 §4.3）

> 关键区别：**取消勾选「启用后台自动导入」= 只停后台扫描，导入接口保留**；而点「禁用」按钮 = 整个插件卸载，导入接口一起失效。WorkBuddy 接管场景必须用前者。

### 4.3 定位微信 PDF 目录

微信 PC 版的文件存储目录形如：

```
D:\WeChat\xwechat_files\wxid_<你的id>\msg\file
```

按「文件 → 设置 → 文件管理」里的存储路径找到它。这就是 `scan_pdf_dir.py` 的 `--source` 参数要指向的目录。

### 4.4 配置 Obsidian + Research Bridge（AI 阅读前置）

1. Obsidian 新建/打开一个库，安装「Research Bridge」插件
2. 在 Research Bridge 设置里连接 Zotero 数据目录
3. 在 Research Bridge 的 AI 设置里填入你的 AI 提供商（如 OpenAI / 本地模型）与 API Key

只有完成第 3 步，才会自动生成 AI 文献阅读任务；否则仅同步文献卡片。

## 5. 运行方式

### 5.1 目录扫描分流（论文 vs 个人资料）

用项目 venv 运行，参数均可覆盖默认值：

```powershell
.\.venv\Scripts\python.exe batch\scan_pdf_dir.py `
  --source "D:\WeChat\xwechat_files\wxid_xxx\msg\file" `
  --archive "D:\PaperFlow\个人资料" `
  --state-path "D:\<Zotero数据目录>\wechat-zotero-importer\standalone-state.json"
```

行为：
- 论文 → 调 `/wechat-zotero/import` 导入 Zotero 分类
- 个人资料（文件名含「述职/证明/发票/合同/证书」等关键词）→ 复制到 `个人资料\<年份>\`，不删原文件
- 用 SHA256 去重，重复不重复导入

### 5.2 端到端下载入库（DOI/链接 → Zotero）

```powershell
.\.venv\Scripts\python.exe batch\orchestrate.py `
  --scansci-python "D:\python\scansci-venv\Scripts\python.exe"
```

`--scansci-python` 必须指向 **scansci-pdf 套件自己的 venv Python**（需含 certifi）。这一步会：领取队列 → 解析 DOI → scansci 下载 → 校验身份 → 导入 Zotero → 观察笔记。

### 5.3 定时自动运行

推荐用 WorkBuddy 定时自动化，或 Windows 任务计划程序，每天固定时间执行 5.1 + 5.2。示例（任务计划程序）：

```powershell
schtasks /Create /SC DAILY /ST 14:00 /TN "PaperFlow" `
  /TR "D:\PaperFlow\.venv\Scripts\python.exe D:\PaperFlow\batch\scan_pdf_dir.py"
```

## 6. 目录结构

```
wechat-zotero-importer/
├── install.ps1              # 一键安装脚本（隔离 venv）
├── requirements.txt         # 项目依赖清单
├── batch/                   # 核心脚本
│   ├── scan_pdf_dir.py      #   目录扫描分流（论文/个人资料）
│   ├── orchestrate.py       #   端到端编排（下载→入库→观察）
│   ├── library_handoff.py   #   Zotero 导入门禁
│   ├── observe_handoff.py   #   只读观察笔记
│   ├── scansci_adapter.py   #   scansci 套件隔离适配
│   └── tests/               #   单元测试
├── receiver/                # 微信回调接收器（服务端骨架）
├── client/                  # 本地桌面客户端（Tk 配置窗口）
├── workbuddy/               # WorkBuddy 技能包
└── docs/                    # 文档与指南
```

## 7. 常见问题排查

| 现象 | 原因 | 解决 |
|---|---|---|
| `/wechat-zotero/import` 返回 404 | 插件被禁用/未加载 | Zotero 里启用插件（不是「禁用」） |
| 返回 401 | bridge-token 不匹配 | 检查 `%LOCALAPPDATA%\WeChatZoteroImporter\bridge-token` |
| 返回 400 `path is required` | 请求缺参数 | 按 `scan_pdf_dir.py` 的 payload 构造 |
| 下载阶段 `download_failed` | scansci venv 缺 certifi 或路径错 | 确认 `--scansci-python` 指向正确 venv |
| `ModuleNotFoundError: pypdf` | 未用项目 venv 运行 | 用 `.venv\Scripts\python.exe` 运行 |
| 非论文被导入 Zotero | 分流关键词未命中 | 在 `scan_pdf_dir.py` 的 `PERSONAL_KEYWORDS` 增补 |
| AI 阅读不触发 | Research Bridge 未配 AI Key | 见 §4.4 第 3 步 |

## 8. 哪些内容无法随包分发

以下内容**绑定作者本人机器或账号，无法（也不应）打包给他人**，需要每个用户自行准备：

| 内容 | 为什么无法分发 |
|---|---|
| 微信文件目录绝对路径 | 每台电脑微信存储路径不同 |
| 微信助理/公众号绑定 | 绑定的是作者个人微信账号 |
| Zotero / Obsidian 数据目录 | 用户各自的数据 |
| bridge-token | 鉴权凭据，随插件首次启用自动生成 |
| scansci-pdf 套件 + venv | 第三方套件，含版权/许可，需用户自行安装并审查 |
| 论文 PDF 与个人资料 | 用户隐私，绝不入包 |

**随包分发的内容**：源代码、`install.ps1`、`requirements.txt`、本手册、WorkBuddy 技能包（`workbuddy/`）。这些不含任何凭据、路径或隐私数据。

## 附：快速自检清单

安装完成后，按顺序验证：

1. `install.ps1` 执行成功，`.venv\Scripts\python.exe` 存在
2. `.\.venv\Scripts\python.exe -c "import pypdf"` 无报错
3. Zotero 运行中，浏览器访问 `http://127.0.0.1:23119/connector/ping` 返回「Zotero is running」
4. `scan_pdf_dir.py` 干跑，输出 JSON 报告，`scanned` 数字正确
5. 一篇真实论文能走完下载 → 入库 → 出现在 Zotero 对应分类

全部通过即表示安装成功。
