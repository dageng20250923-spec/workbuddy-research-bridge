## 已实现

- 官方明文回调的GET URL校验、POST验签，时间窗口与重复参数检查。
- 只接受配置的目标公众账号及发送者OpenID；备注不是身份。白名单未填或账号不明时拒绝启动，不先读所有人的消息再挑选。
- 纯文字中的DOI/doi.org地址/公众号文章链接提取；不处理文章卡片、附件、群消息或历史聊天，不打开微信窗口。
- 事务性SQLite持久化、MsgId字符串去重、同一候选去重，写失败返回503而不假称成功；重启可保留待处理候选。
- 本地导出待处理JSON，但paper_verified=false、pdf_url=null；识别到DOI不等于论文身份核验/下载地址定位成功。导出不改变完成状态。
- 被动文本自动回复：成功入队/重复/非文本/无候选时，按微信被动回复协议返回固定 text/xml 确认文案（“已收到，正在排队整理”等）。回复仅含确定性安全文案，不回显 DOI、正文、发送方身份或队列内容；非文本消息与未知状态回 success 表示不回复。该能力 2026-10-09 新增，84 项测试通过。
- 不保存完整Content/XML或无关聊天正文；队列仅候选值/出处，回执存账号哈希、消息ID和带密钥发送方哈希。HTTP队列查看/静态文件服务未开放，默认请求日志禁用，避免泄漏回调签名或URL。

## 现阶段运行边界

仅绑定127.0.0.1，不能直接改为0.0.0.0公网监听。未来可经明确批准的公网HTTPS转发接入，或把实现改造成正式托管服务。不是直接把个人微信聊天变成可读接口。

当前是Python标准库开发原型，使用已有D:/python/python/python.exe。最终接收服务需独立运行并受维护，不需要Codex维持微信回调；但用户刚选的后续定时批量下载会依赖Codex。服务端开发原型使用Python，不表示普通用户必须手工执行Python命令；正式部署/分享方式尚未完成。

明文模式验签遵循微信协议：签名涵盖Token、timestamp、nonce，**不涵盖XML正文**；HTTPS和可信托管/转发方十分重要。加密模式签名/解密未实现，收到Encrypt/msg_signature等会明确拒绝，不偷偷降级。不要当成可直接公开发布的多用户生产服务。

## 一次性配置（公网方案确认后才执行）

1. 运行初始化命令生成runtime/local-config.json，随机Token只写本地文件、不显示在聊天/日志；文件已存在时不会覆盖。
2. 在自己的测试号后台核实开发者账号标识，对应回调ToUserName，填写account_id；从受信任的测试号用户列表核实发送方OpenID，填allowed_senders数组。不要把AppSecret/Token/OpenID完整内容贴到Codex聊天，使用本地私密配置。
3. callback_token与账号后台Token必须一致。此原型不需要把AppSecret写入源码；完整后台功能若另需AppSecret再单独设计。
4. 配置目录在放入真实秘密前应限制为当前用户可读写；本原型不自动更改Windows ACL。share包必须排除runtime、.tmp、私密配置和数据库。
5. 公网通道/服务器/数据处理边界获批准后，接收地址为其固定或临时域名下/wechat/callback，不暴露Zotero本地接口。
6. 用户在账号后台自行填写URL和Token，官方URL校验成功后，再通过现有测试号对话发送已知DOI和公众号文字URL进行真实验收。旧文章卡片选择器失败不是文字回调失败；也不保证测试号会自动变成普通联系人。

开发命令（都从本目录运行，可控TEMP/TMP应设置为本目录.tmp；本轮未执行init/serve/export生产动作）：

```powershell
& 'D:\python\python\python.exe' -B .\receiver.py init
& 'D:\python\python\python.exe' -B .\receiver.py serve
& 'D:\python\python\python.exe' -B .\receiver.py export
```

运行测试可直接使用Test-Receiver.ps1，脚本会把TEMP/TMP设置到D盘。测试使用虚构账号/发送者/Token，不访问微信或出版社。
